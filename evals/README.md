# 평가

edgar 스킬의 답 장면을 재는 자산이다. 도구 숫자의 정확성은 `tests/`(오프라인)와 `scripts/live_check.py`(실측)가 맡고, 여기서는 Claude가 그 숫자로 **답을 제대로 쓰는지**를 본다.

| 파일 | 하는 일 |
|---|---|
| `evals.json` | 질문 9개와 채점 기준 34개. 기대값은 2026-11-06 실측 |
| `trigger_queries.json` | 발동해야 할 질문 9개, 발동하면 안 되는 질문 5개(dart와 겹침 점검 포함) |

## 돌리는 법

DART 스킬 `evals/README.md`와 같은 skill-creator 절차를 쓴다. 질문마다 새 버전과 비교 버전을 함께 돌리고, 답(answer.md)을 기준별로 채점해 통과율·시간·토큰을 비교한다.

## 갱신 기준

새 10-Q·10-K·13F가 나오면 질문 1·2·7의 기대값이 바뀐다. `scripts/live_check.py`를 먼저 돌려 도구가 맞는지 보고, 그다음 기대값을 고친다.
